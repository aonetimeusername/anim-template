# Новый ролик

Тема и пожелания пользователя: $ARGUMENTS

Работай строго по `CLAUDE.md` (прочитай целиком), формат — `docs/FORMAT.md`, сцены — `docs/SCENES.md`.

1. Придумай имя папки латиницей (`eps/<имя>`), скопируй туда `eps/example` (только `story.py`, `mix.py`, `build/script.json`).
2. Напиши сценарий `build/script.json` (30–45 с, хук в первой фразе, правила с причинами, зло действует каждые 5–7 с, финал из правил) и список кадров: фраза → сцена → что происходит. **Покажи пользователю и дождись «да».**
3. Недостающие сцены — новые файлы в `engine/scenes/`. Каждую проверь `scene_test.py` и посмотри лист сам (Read картинки). Исправляй, пока не читается с первого взгляда.
4. `python build.py <имя> --no-render` → перепиши `story.py` и `mix.py` под новый текст (времена только через t/te/wf) → снова `--skip-tts --no-render`.
5. `python build.py <имя> --skip-tts --sheet` → открой `eps/<имя>/qa/sheet.jpg`, пройди чек-лист из CLAUDE.md, исправь.
6. `python build.py <имя> --skip-tts` → проверь, что mp4 есть, и коротко расскажи пользователю, что получилось и где файл.
