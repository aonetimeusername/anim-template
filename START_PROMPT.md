# Промпты для ИИ-агента

Скопируйте нужный текст в Claude Code (или другой агент), открытый в папке проекта. Вместо `<...>` впишите своё.

## Первый запуск

```
Прочитай CLAUDE.md, docs/FORMAT.md и docs/SCENES.md. Проверь, что всё установлено,
и собери пример: python build.py example. Если что-то не работает — почини установку
и объясни мне простыми словами, что было не так.
```

## Новый ролик

```
Сделай новый ролик по инструкции из CLAUDE.md.
Тема: <о чём ролик, например: «если ночью в лифте кнопка этажа нажалась сама»>.
Длина 30–45 секунд, формат и ритм — по docs/FORMAT.md.

Порядок:
1. Сначала покажи мне сценарий (script.json) и список кадров: какая сцена на какой фразе.
   Используй готовые сцены из docs/SCENES.md, а недостающие предложи нарисовать.
2. После моего «да» нарисуй новые сцены и проверь каждую через scene_test.py — открой лист
   кадров и посмотри сам: читается ли сцена, ничего ли не налезает на субтитры, что-то ли движется.
3. Озвучка и раскадровка (build.py --no-render), потом лист кадров (--sheet). Посмотри лист сам,
   пройди чек-лист из CLAUDE.md и исправь всё, что не так.
4. Полный рендер. Пришли мне путь к видео и коротко напиши, что получилось.
```

## Правки готового ролика

```
Ролик eps/<имя>: <что не нравится, например: «середина скучная», «финал непонятный»,
«на 12-й секунде рука выглядит странно»>. Исправь, проверь листом кадров и пересобери.
Если текст не менялся — без новой озвучки (--skip-tts).
```

## Описание для публикации

```
Напиши описание к ролику eps/<имя> для TikTok: одна-две фразы как от живого человека,
вопрос зрителю, 3–5 хэштегов по теме. Без канцелярита, списков и «захватывающих историй».
```
