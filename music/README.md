# Музыка (music/)

Пример ролика ищет `music/theme.mp3`: если файла нет, ролик собирается без музыки.
В своём `mix.py`: `M.music([("файл.mp3", с_какой_секунды_файла, с_какой_секунды_ролика, до_какой_секунды_ролика, fade_in)], level_db=-10)`.

Где брать бесплатно:
- https://pixabay.com/music/ (жанры horror, dark ambient, suspense);
- https://mixkit.co/free-stock-music/;
- YouTube Audio Library (в YouTube Studio).

Музыка должна быть на 9–13 дБ тише голоса (mixlib.py делает это сам) и обрываться в момент поворота сюжета.
Популярные треки из TikTok лучше добавлять в приложении при публикации, а не вшивать в файл.
