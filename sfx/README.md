# Звуки (sfx/)

Шаблон работает и без файлов: всё нужное синтезирует mixlib.py. Свои звуки сделают ролик богаче.

- Положите файл сюда и используйте в `mix.py` ролика: `M.put(ev("door.mp3"), время, db(-18))`.
- Подложки подхватываются сами, если есть файлы с такими именами: `room.mp3` (гул комнаты), `drone.mp3` (низкий тревожный фон), `tick.mp3` (часы).

Где брать бесплатно (читайте лицензию каждого сайта):
- https://mixkit.co/free-sound-effects/ — без регистрации, можно в роликах;
- https://pixabay.com/sound-effects/ — без указания автора;
- https://freesound.org — огромный выбор, смотрите лицензию (CC0 — без условий, CC-BY — указать автора в описании).

Сами файлы в репозиторий не попадают (.gitignore): лицензии многих сайтов запрещают их распространять.
